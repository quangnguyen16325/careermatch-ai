
# Student Navigation Flow

## 1. Authentication Flow

Login -> Dashboard

Register -> Email Verification -> Login

Forgot Password -> Reset Password -> Login

## 2. Profile Flow

Dashboard -> Student Profile -> Edit Profile

Student Profile -> Skill Editor

## 3. CV Flow

Dashboard -> CV Management -> CV Upload

CV Upload -> CV Analysis Progress

CV Analysis Progress -> Extracted Skills

## 4. Job Flow

Dashboard -> Job Search -> Job Filters

Job Search -> Job Detail -> Match Explanation

Job Detail -> Apply -> Application Confirmation

## 5. Application Flow

Dashboard -> Application Tracking

Application Tracking -> Interview Responses

## 6. Notification Flow

Dashboard -> Notification Inbox

Notification Inbox -> Notification Detail

## 7. Navigation Rules

- Protected Student screens require authentication.
- Unauthenticated users are redirected to Login.
- Students can access the main modules through navigation.
- Match Score is informational and does not make
  automatic hiring decisions.
